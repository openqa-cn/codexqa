# Support

For reproducible bugs, open a [bug report](https://github.com/openqa-cn/codexqa/issues/new?template=bug_report.yml).

For questions, ideas, and implementation discussion, use [GitHub Discussions](https://github.com/openqa-cn/codexqa/discussions).

When asking for help, include the skill version or commit, operating system, agent, test framework, command, expected result, and actual result. Never include credentials, customer code, private logs, or personal data.

Enterprise pilots, private deployment, training, and consulting: contact hello@openqa.cn.
