    它是什么What this is

    This repository is not one service. It is a row of skills: defect scan, root-cause diagnosis, test data, case generation, and browser replay. Each skill ships its own scripts and is installed by copying its own directory, so the code falls into islands that do not call each other.

    The largest, most connected island is defect scan and diagnosis. P02 is the hub: the scan pipeline, the README preview scripts, and the example-repo entry points. P05 installs the scan agent and tools. P11 parses exceptions for root-cause diagnosis. A change to P02 touches all three.

    Test data and browser replay are the other two islands. Test data enters through the tool-binding pipeline in P06, passes the config and adapters in P04, and is checked by the scenario suites in P07. Browser replay is a dense back-and-forth between the runner in P03 and the decision agent in P10. P01 is the code-review rule scanner and has no calls to the other modules.
