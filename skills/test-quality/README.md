# test-quality

Review whether a test meaningfully proves behavior rather than merely passing.

## Use when

Reviewing AI-generated tests, regression suites, or tests with suspiciously high pass rates.

## Install

Copy or reference [`SKILL.md`](SKILL.md) from your compatible coding agent.

## Output

Findings with severity, location, reason, suggested change, and a reproducible example.

## Limitations

This workflow does not replace domain review, security review, or a complete test strategy.
