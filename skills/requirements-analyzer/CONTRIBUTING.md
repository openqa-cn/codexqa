# Contributing

This skill is a vendor-neutral, Apache-2.0 Agent Skill for requirement quality-and-risk analysis.

## Principles

1. The `SKILL.md` `name` is `requirements-analyzer` and must match this directory.
2. Keep examples portable: no company names, internal hostnames, or staff IDs. Prefer `example.com`, `Northwind`, `customerId`, `stock`.
3. Do not add a second output outline. One register (`RA-xx`) only.
4. Public docs and identifiers are written in English; `.zh-CN.md` tracks the English source.

## Checks

- Grep the tree for organization-specific leftovers.
- If you add a file the agent must see, mention it from `SKILL.md` or `prompts/requirements-analyzer.md`.
- Human-facing pages: `README.md`, `HOW_IT_WORKS.md`, `KNOWN_LIMITATIONS.md` and their `.zh-CN.md`.

## Reporting security issues

See the repository [SECURITY.md](https://github.com/openqa-cn/codexqa/blob/main/SECURITY.md).
