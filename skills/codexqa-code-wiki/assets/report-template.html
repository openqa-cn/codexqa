术语 本页用词

  • 模块：表格里的 P01、P02。是一组经常一起被改到的代码，不是评分，也不等于一个目录名。
  • 会调用：读代码时能从这一组走到下一组。建议阅读顺序只沿这种真实调用走。
  • 最关键的模块：很多模块会调用它，或者它会调用很多模块。改它之前先看对外接口。
  • 符号数：这组里收录了多少函数、类和类型，用来比谁更大，不是质量分。
