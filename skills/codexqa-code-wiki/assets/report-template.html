术语 本报告用词

  • 模块 / 社区：编号 p01 起，对应一次导出里的一页。
  • 依赖：社区之间的有向边，阅读路径只沿这条边走。
  • 枢纽：依赖多或被调用多，先读对外接口。
  • 规模：该页收录的符号数量，用来排序，不是质量分。
