# Directory and listing tracker

Submit only developer-relevant, human-reviewed listings. Primary link: `https://openqa.cn/`. Secondary link: `https://github.com/openqa-cn/codexqa`. Skip paid link farms and bulk “1000 directories” services.

Status values: `todo` · `submitted` · `live` · `rejected` · `n/a`.

## Rules

- One listing per property; do not spam mirrors.
- Match the category (testing, SAST, Agent Skills, developer tools).
- After `live`, add the referring URL to the quarterly measurement sheet.
