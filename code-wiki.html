    它是什么

    这个仓库不是一个服务，而是一组并排放着的 skill：缺陷扫描、根因诊断、测试数据造数、用例生成、浏览器界面回放等。每个 skill 自带脚本，安装时只复制自己的目录，所以代码天然分成几组互不调用的「岛」。

    规模最大、连接最多的一组是缺陷扫描与诊断：P02 是枢纽，既放着缺陷扫描的主流程，也放着 README 预览重建脚本和示例仓库的入口；P05 是扫描用的 Agent 与工具安装，P11 是根因诊断的异常解析。改 P02 会同时碰到这三条线。

    测试数据造数和浏览器界面回放是另外两组：前者从 P06 的工具绑定流水线进来，经 P04 的配置与适配层，再由 P07 的场景套件校验；后者是 P03 执行器和 P10 决策智能体之间的密集往来。P01 是代码评审的规则扫描脚本，和其他模块没有调用关系。
