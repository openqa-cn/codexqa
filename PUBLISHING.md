# Publishing skills

The repository is the source of truth for the public skill set. A published skill must:

1. have matching `name` metadata and directory name;
2. include `SKILL.md` and a human-facing `README.md`;
3. include acceptance criteria and a reproducible example;
4. state supported agents and frameworks;
5. state limitations and maturity status;
6. pass repository checks;
7. be included in `skills.json`.

Do not publish customer-specific instructions, secrets, private URLs, or claims that cannot be reproduced.
