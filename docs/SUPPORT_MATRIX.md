# Support matrix

This table is intentionally conservative. A tool is marked **Supported** only when the repository contains a reproducible example and CI or maintainer verification for it.

| Component | Status | Notes |
| --- | --- | --- |
| Skill workflow contracts | Available | Local Markdown instructions |
| Evidence Schema v0.1 | Available | See `schemas/evidence.schema.json` |
| Claude Code | Experimental | Adapter and example pending |
| Codex | Experimental | Adapter and example pending |
| Cursor | Experimental | Adapter and example pending |
| Playwright | Experimental | Reproducible adapter pending |
| pytest | Experimental | Reproducible adapter pending |
| GitHub Actions | Experimental | Repository hygiene workflow is available |

Status definitions: **Available** means published in this repository; **Experimental** means usable with known limitations; **Supported** requires a maintained reproducible integration.
